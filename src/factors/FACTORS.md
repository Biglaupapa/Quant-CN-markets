本文件记录本框架中每个因子的构建逻辑、关键参数、数据来源及重要设计决策。
所有设计决策均附文献依据或经验判断说明，供后续回顾和修改参考。

## 全局设置

### 回测起点

**当前设置**：`BACKTEST_START = "2007-01-01"`

数据本身从 **2005-01-04** 起可用（Choice 迁移后的起点）。选 2007 是**主动判断**：
2005~2006 年 A 股仅 1300~1400 只、股改期间大量停牌、估值数据质量差。
各因子统一对齐至此起点，使单因子与多因子合成结果具有可比性。

### 价格复权开关（`USE_ADJ_PRICE`）

**位置**：`src/config/settings.py`

```python
USE_ADJ_PRICE = True   # True = 后复权；False = 不复权
```

影响以下因子的价格字段选择：`reversal_20`、`momentum_12_1`、`amihud_zero_adj`、
`roll_spread`、`overnight_ret`、`volatility_30`。

**不受此开关影响的因子**（原因见各因子说明）：
- `amihud`：日度收益率计算必须使用后复权价，否则除权日产生虚假大收益
- `cs_spread`：跨日高低价比较必须使用复权价（见 cs_spread 说明）
- `turnover_20` / `turnover_20_neutral`：仅使用 `turn` 字段，不涉及价格

### 中性化变量说明

市值中性化统一使用 **log(流通市值)**，数据源为 `neg_market_value`（Choice，2005+）。
不再使用 `close × float_shares` 估算（该方式为历史遗留，已替换）。

### 分组方法（`strategy/optimizer.group_by_score`，2026-10-05 起）

- **只在组建日股票池内分组**：`engine.group_return` 先把因子限定在「下期收益非空」= t 月末组建日股票池的股票上，
  再切分位（与 `calc_ic` 先掩码后排秩一致；2026-10-04 修复，见方法文档 §二十一）
- **成员划分与 `pd.qcut` 完全一致**（`Series.quantile` 线性插值、右闭区间），取值相同的股票必落同一组
- **标签锚定两端**：分位点重合（取值大量并列）时保留原分位编号，最低一档 = G1、最高一档 = G5。
  原 `qcut(duplicates="drop", labels=False)` 会从 0 重新编号，把最高一档标成 G4，导致 G5 与多空整月 NaN
  （2026-10-05 修复，方法文档 §二十四；113 个因子中 108 个逐格不变）
- 离散因子（`f_score` 0–9、`ni_inc8q` 0–8）五分位无法均分：中间组常为空、各组人数不均，多空 = 最高一档 − 最低一档。
  体检脚本 `scripts/audit_groups.py`
- **组内加权：等权与 A 股市值加权并报**（2026-10-06，#40）：分组成员相同，市值加权用 t 月末 A 股市值
  （`universe.formation_market_cap`，与规则 g 同一函数）。主文件为等权，市值加权另存 `<因子>_vw_*`。
  市值加权下 81% 的因子夏普下降、合成 1.50 → 0.82（方法文档 §二十七）——**等权结果高度依赖组内小市值股票**

## 微观结构因子（`src/factors/microstructure.py`）

### 1. reversal_20 — 短期反转

**计算公式**：

$$\text{Reversal}_{i,t} = \frac{P_{i,t}}{P_{i,t-20}} - 1$$

过去 20 个交易日的累计收益率，月末取值。

**因子方向**：负向（G1=过去最跌 → 未来反弹；G5=过去最涨 → 未来回调）

**数据**：`close_adj`（或 `close`，由 `USE_ADJ_PRICE` 控制）

**参数**：`REVERSAL_WINDOW = 20`（交易日）

**中性化**：无

**回测结果（2004-2026）**：
- IC均值 = -0.066，ICIR = -0.44，|IC|>0.02占比 = 89%
- G1年化+16.6%，G5年化+0.4%，单调性较好但 G1/G2 差距小

---

### 2. momentum_12_1 — 中期动量

**计算公式**（月度）：

$$\text{MOM}_{i,t} = \frac{P_{i,t-1}}{P_{i,t-12}} - 1$$

跳过最近 1 个月（`t-1` 到 `t`），避免短期反转干扰，使用 12-1 个月累计收益。

**因子方向**：理论正向（强者恒强），但 A 股实证失效

**数据**：`close_adj`（月度）

**参数**：`MOMENTUM_LONG = 12`，`MOMENTUM_SKIP = 1`

**中性化**：无

**回测结果（2004-2026）**：
- IC均值 = -0.014，ICIR = -0.08，接近零，**因子无效**
- G1-G5 呈倒 U 型（G3 最高），分组无单调性

**A股特殊性**：A 股以散户为主，追涨杀跌盛行，过去 12 个月涨幅最大的股票
（G5）往往已被过度定价，后续反转而非延续。与海外动量效应相反，
是 A 股定价机制的结构性特征，不是计算错误。

### 3. turnover_20 — 换手率（无中性化）

**计算公式**：

$$\text{TURN}_{i,t} = \frac{1}{20} \sum_{d=t-19}^{t} \text{turn}_{i,d}$$

过去 20 个交易日的平均换手率，月末取值。

**因子方向**：负向（低换手率 → 高未来收益）

**数据**：`turn`

**参数**：`TURNOVER_WINDOW = 20`；窗口内至少 `MIN_ROLLING_VALID_DAYS`（=10）个有效日
（2026-10-05 前 `rolling` 未传 `min_periods`，实际要求 20 天全有，一天停牌即整窗 NaN；修复后池内覆盖 97.8% → 99.7%，方法文档 §二十三）

**中性化**：无（原始信号）

**回测结果（2004-2026）**：
- IC均值 = -0.096，**ICIR = -0.72**，|IC|>0.02占比 = 89%
- G1年化+23.6%（Sharpe=0.79），G5年化-1.3%，**G1-G5单调递减完美**
- **最强因子**，信号最稳定

**经济逻辑**：低换手代表机构持仓稳定、散户炒作少，筹码结构优良。

---

### 3b. turnover_20_neutral — 换手率（流通市值中性化）

同 `turnover_20`，但在截面上对 log(流通市值) 回归取残差，剔除换手率与规模的线性相关。

**数据**：`turn` + `neg_market_value`（中性化变量）

**中性化**：log(流通市值)，`neg_market_value`（Choice，2005+）

**用途**：与 `turnover_20` 对比，判断市值中性化是否提升因子质量。

### 4. amihud — Amihud 非流动性（无中性化）

**计算公式**（Amihud, 2002）：

$$\text{ILLIQ}_{i,t} = \frac{1}{D} \sum_{d=1}^{D} \frac{|R_{i,d}|}{\text{Amt}_{i,d} / 10^6} \times \text{ILLIQ\_SCALE}$$

其中 $D$ 为过去 3 个月的交易日数，$\text{Amt}$ 为成交额（元），除以 $10^6$ 换算为百万元，
`ILLIQ_SCALE = 1e5` 为缩放系数，使因子数值在合理范围内。

**滞后处理**：因子整体滞后 `AMIHUD_LAG_MONTHS = 1` 个月，避免月末数据前瞻偏差。

**因子方向**：正向（ILLIQ 越大 = 流动性越差 = G5；G5 未来收益越高）

**数据**：`close_adj`（后复权，计算日度收益率必须复权）、`amt`（成交额，元）

**参数**：`AMIHUD_WINDOW_MONTHS = 3`，`AMIHUD_LAG_MONTHS = 1`，`ILLIQ_SCALE = 1e5`

**中性化**：无（原始信号）

**回测结果（2004-2026）**：
- IC均值 = +0.049，ICIR = +0.31，|IC|>0.02占比 = 91%
- G1年化+5.1%，G5年化+22.8%，**G1-G5单调递增完美**
- LS年化+16.6%，**LS最大回撤仅-24.9%**（全部因子中最稳健）

**注意**：`close_adj` 不受 `USE_ADJ_PRICE` 控制，始终使用后复权价。

---

### 4b. amihud_neutral — Amihud 非流动性（流通市值中性化）

同 `amihud`，但截面回归剔除与 log(流通市值) 的线性相关后取残差。

**数据**：`close_adj`、`amt` + `neg_market_value`（中性化变量）

**中性化**：log(流通市值)，`neg_market_value`（Choice，2005+）

**用途**：与 `amihud` 对比，判断剥离规模效应后流动性信号的纯度。

### 5. amihud_zero_adj — Amihud 零交易日调整版（无中性化）

**计算公式**（IREF-sentiment 版本）：

$$\text{ILLIQ\_ZA}_{i,t} = \ln\!\left(\text{mean}\!\left(\frac{|R_{i,d}|}{\text{Vol}_{i,d}}\right)\right) \times (NT_t + 1)$$

其中 $NT_t$ 为当月零交易日（成交量为 0）占比，对零流动性日期施加更大惩罚。
使用成交量（股数）而非成交额。

**因子方向**：正向（同 amihud）

**数据**：`close_adj`、`volume`（成交量）

**中性化**：无（原始信号）

**回测结果（2004-2026）**：
- IC均值 = +0.044，ICIR = +0.27，|IC|>0.02占比 = 92%（全部因子最高）
- LS年化+14.0%，LS最大回撤-30.4%

**与 amihud 关系**：方向相同，强度略弱，但信号频率更稳定。两者相关性较高，
实际使用时选一个即可，amihud 在 IC 强度上更优。

### 6. cs_spread — Corwin-Schultz 高低价价差

**计算公式**（Corwin & Schultz, 2012）：

$$\beta = (\ln H_t/L_t)^2 + (\ln H_{t+1}/L_{t+1})^2, \quad
  \gamma = (\ln \max(H_t,H_{t+1}) / \min(L_t,L_{t+1}))^2$$

$$\alpha = \frac{\sqrt{2\beta}-\sqrt{\beta}}{3-2\sqrt{2}} - \sqrt{\frac{\gamma}{3-2\sqrt{2}}}, \quad
  \text{Spread} = \frac{2(e^\alpha - 1)}{1+e^\alpha}$$

月度均值，要求至少 `MIN_ROLLING_VALID_DAYS` 个有效值。

**负值处理：截断为 0**（Corwin & Schultz 原文建议，原因见下）

当 2 日波动率远大于 1 日波动率的 2 倍时，α 变负，导致 spread 估计值为负数。
CS Spread 的负值出现在**输出端（spread 值本身）**，bid-ask spread 经济含义天然 ≥ 0，
负值只是采样噪音的产物，截断为 0 是合理的下界修正。

**必须使用复权高低价**：除权日前后不复权的高低价差异可达数倍，导致跨日价差估计严重失真。
故 `high_adj`/`low_adj` **不受 `USE_ADJ_PRICE` 控制**，始终使用复权价。

**因子方向**：负向（G1=价差最小/最流动 → 未来收益最高）

**数据**：`high_adj`、`low_adj`

**中性化**：无

**回测结果（2004-2026）**：
- IC均值 = -0.057，ICIR = -0.46，|IC|>0.02占比 = 86%
- G1年化+15.5%，G5年化+4.8%

---

### 7. roll_spread — Roll 价差

**计算公式**（Roll, 1984）：

$$S_{i,t} = 2\sqrt{-\text{Cov}(r_{i,d}, r_{i,d-1})} \quad \text{当 } \text{Cov} < 0$$

**核心设计决策：Cov ≥ 0 时置 NaN（非 0）**

Roll 方法的理论前提是 bid-ask bounce 产生负序列自相关。Cov ≥ 0 直接违反此前提，
不是"估计出了负的价差"，而是"连判断价差是否存在的能力都没有了"——置 NaN，非 0。
（置 0 会导致约 57% 的数据同值，`pd.qcut` 无法形成有意义的 5 个分组。）

**因子方向**：负向（G1=Roll spread 最小/最流动 → 未来收益最高）

**数据**：`close_adj`（由 `USE_ADJ_PRICE` 控制）

**中性化**：无

**回测结果（2004-2026）**：
- IC均值 = -0.053，ICIR = -0.499
- G1年化+14.4%，G5年化+4.2%，单调性良好

### 8. overnight_ret — 隔夜收益率

**计算公式**：

月内所有交易日隔夜收益率的均值。

**因子方向**：理论正向，A 股实证接近无效

**数据**：`open_adj`（或 `open`）、`close_adj`（或 `close`），由 `USE_ADJ_PRICE` 控制

**中性化**：无

**回测结果（2004-2026）**：
- IC均值 = +0.010，ICIR = +0.13，LS年化仅+0.8%，**基本无效**

### 9. volatility_30 — 短期波动率

**计算公式**：

$$\text{VOL}_{i,t} = \text{std}(r_{i,d})_{d \in [t-29, t]}$$

过去 30 个交易日日度收益率的标准差，月末取值。

**因子方向**：负向（低波动率 → 高未来收益）—— 低波动异象

**数据**：`close_adj`（由 `USE_ADJ_PRICE` 控制）

**参数**：`VOLATILITY_WINDOW = 30`；窗口内至少 `MIN_ROLLING_VALID_DAYS`（=10）个有效日
（2026-10-05 修复，同 turnover_20；池内覆盖 92.6% → 99.9%）

**中性化**：无

**回测结果（2004-2026）**：
- IC均值 = -0.064，ICIR = -0.37，|IC|>0.02占比 = 89%
- G1年化+14.2%（Sharpe=0.52），G5年化+3.7%

### 11. bm — 账面市值比（Book-to-Market）

**计算公式**：

$$\text{B/M}_{i,t} = \log\!\left(\frac{1}{\text{PB}_{i,t}}\right) = -\log(\text{PB}_{i,t})$$

参考 Fama-French HML 构建逻辑，使用 log 变换后的 B/M 而非原始 PB。

**数据**：`pb.csv`（Database，Choice `PB`，2005+），PB ≤ 0 置 NaN

**中性化**：无

**因子方向**：正向（B/M 越高 = 价值股 = 正向信号）

**与 pb 的关系**：方向相反（pb 负向，bm 正向），变换后的 bm 分布更接近正态，
理论上更适合截面回归。两者可对比单因子 IC，选择更优的版本用于合成。

### 12. pe_ttm — 市盈率 TTM（静态）

其中净利润 TTM 是过去连续四个季度净利润之和（即滚动12个月累计净利润，
基于**已披露**的最新年报或半年报，属于静态的历史会计数据）。

**计算公式**：月末截面值，负值（亏损公司）置 NaN。

**数据**：`pe_ttm.csv`（Database，Choice `PETTM`，2005+）

**中性化**：无

**因子方向**：负向（低 PE TTM = 价值股）

**回测结果（2007-01 ~ 2026-07）**：

- 与 `pe1` 强度已基本相当（-0.0329 / -0.222）——两者现在都是静态口径，
  差别只在分母是 TTM 还是最近年报，见下节

> **换源提示**：2026-08-17 由 Datayes 切至 Choice `PETTM`。近年逐位相等，
> 但 **2012 年截面秩相关仅 0.52、中位相对差 18.6%**——早期两家口径差异很大，
> 该因子的早期历史结果已改变。主文档 §3.3「已验证逐位相等」只在近年成立。

#### ⚠️ 这个因子名是历史遗留，下面这段必须读

**旧定义（2026-08-17 之前）**：Datayes `pe1` = 市值 ÷（最新单季净利 × 4），
是**单季年化动态市盈率**。

反推验证（2024-06-28 截面）：

| 个股 | 旧 `pe1` | 手工核算 | Choice `PE` |
|------|---------|---------|------------|
| 五粮液 | 8.85 | 2024Q1 净利 140.5 亿 × 4 = 562 亿；市值约 4970 亿 → **8.85** ✓ | 16.45 |
| 贵州茅台 | 19.15 | 同法 → **19.15** ✓ | 24.67 |

旧口径是一个**合法且独立**的指标，不是脏数据。

**为什么还是换掉了**：Datayes 于 2026-07-17 停更，而 Choice 的 26 个字段里
**没有净利润**，无法重建单季年化口径。与各候选列的秩相关：

| 对比列 | 2010 | 2016 | 2020 | 2026 |
|--------|------|------|------|------|
| `PE` | 0.43 | 0.35 | 0.20 | 0.42 |
| `PETTM` | 0.50 | 0.43 | 0.30 | 0.47 |
| `ESTPEFTM` | 0.64 | 0.34 | 0.37 | 0.46 |

没有任何一列接近。最终选择用 `PE` 顶替并沿用因子名——
**这是语义替换，不是无损换源。**

**后果**：

| | 旧（Datayes 单季年化） | 新（Choice 静态 PE） |
|---|---|---|
| RankIC | -0.0465 | **-0.0329** |
| ICIR | -0.293 | **-0.222** |
| G1 年化 | +17.07% | **+13.53%** |

**该因子 2026-08-17 之前的所有回测数字都不可与之后比较。**
原「pe1 比 pe_ttm 更及时、ICIR 与 LS 均更优，故选 pe1 入合成」这一论证
**已随口径变更失效**——两者现在都是静态口径，强度也基本相当
（-0.0329 vs -0.0326）。合成池目前仍保留 `pe1`，但这个选择需要重新评估。

### 16. size2 — 流通市值因子

**计算公式**：$\text{SIZE2} = \ln(\text{neg\_market\_value})$

## 2026-08-18 新增：11 个风险 / 流动性风险因子

本轮**没有下载任何新数据**，全部用已有字段构建。原「待激活」清单标注的
`marketrtn_daily.csv` 是一个伪缺口，见下。

### 关键前提：市场收益率序列一直都在

四个因子（`ps_gamma` / `ps_liq_beta` / `ap_beta*` / `capm_beta`）自建库起就写着
「需补 `marketrtn_daily.csv`」。实际上该序列无需下载——`ff3_daily.csv` 的
`MKT` 列按定义就是全市场可投资股票的 **VW 超额收益**（`ff3_builder.py:289`：
`return (vw_ret - rf_aligned).rename('MKT')`），因此

```
r_m = MKT + Rf          # ff3_daily.csv 两列相加
```

即为所需的日度市场收益率（2005-01-05 ~ 2026-08-14，5249 个交易日，日均 0.052%）。
`ap_beta*` 另需的「日度流通市值」就是 `neg_market_value.csv`。
封装在 `microstructure.py: _load_market_return_daily()`。

### 23. capm_beta — CAPM 市场 Beta

**构建**：240 交易日滚动窗口，月末取值，闭式解 β = Cov(r_i, r_m) / Var(r_m)。
用**原始收益**而非超额收益——rf 在截面上是常数，被截距吸收，β 完全相同。
最少 `MIN_ROLLING_VALID_DAYS`(=10) 个有效观测。

**数据**：`close_adj`（日度）+ `ff3_daily`（推 r_m）
**性质**：风险载荷类，非特征类。原始 β 中位数约 1.07（合理）。
**来源**：[af] `factorcal.py: FactorBeta`

### 24-25. beta_smb / beta_hml — FF3 规模 / 价值载荷

**构建**：12 月滚动日度 FF3 回归 `r_i^e = α + β_mkt·MKT + β_smb·SMB + β_hml·HML + ε`
中的后两个系数。

**为什么是新增**：这两个 β **一直在被计算，但一直被丢弃**。原
`_calc_ff3_betas()` 把它们塞进 `result.attrs['beta_smb']`，而 `attrs`
在 `to_csv()` / `read_csv()` 的缓存往返中会丢失——等于每轮白算两个 β。
本轮拆成两个独立因子；`ff3_betas` 本身**口径未动**，仍是 β_mkt，
历史结果逐位不变（IC -0.0084 / ICIR -0.071 已复核）。

四个共用同一组回归的因子（`ivol` / `ff3_betas` / `beta_smb` / `beta_hml`）
现由 `_ff3_rolling_result()` 统一提供，带 `lru_cache`，一轮只跑一次而非四次。

**性质**：**载荷**（对因子收益的协动）≠ **特征**（`size` / `bm` 的市值、账面市值比水平）。
GKX 两者都收，因为在 A 股未必同向——实测 `beta_smb` 与 `size` 方向确实相反。

### 26. ps_gamma — Pastor-Stambaugh Gamma

**构建**：逐月对每只股票做月内日度回归（PS 2003 式 (1)）

```
r^e_{i,d+1} = θ + φ·r_{i,d} + γ·sign(r^e_{i,d})·v_{i,d} + ε
```

`r^e = r_i − r_m`（个股减市场），`v` = 成交额（**百万元**，由 `amt.csv` 的元 ÷ 1e6）。
月内最少 `PS_GAMMA_MIN_OBS`(=10) 个有效交易日。

**性质**：γ 是「成交量推动次日价格反转的力度」，**γ 越负 = 流动性越差**。
方向与 `amihud` 相反（amihud 越高 = 越不流动）。
实测非空样本中 **57% 为负、中位数 -8e-6**，与 PS(2003) 的理论预期一致。

**实现注意**：回归元逐股不同（`sign(r^e)·v` 是矩阵不是向量），
不能走 `_batch_ols` 的「共享 X」路径，需手工组装各阶矩后堆叠解 3×3。
月度标签用**日历月末**（`ym.to_timestamp("M")`）以对齐 `loader.to_monthly`
的 `resample("ME")`——若用当月最后交易日，235 个月里只有 156 个能相交。

**来源**：[af] `factorcal.py: FactorGamma`

### 27. ps_liq_beta — PS 流动性 Beta（36 月滚动）

**构建**四步：
1. 市场流动性水平 γ_t = γ 的**流通市值加权**截面均值
2. 一阶差分 Δγ_t
3. 流动性冲击 L_t = Δγ_t 对其滞后一期做 AR(1) 的**残差**（不可预测部分）
4. 逐股 36 月滚动回归 `r_i = α + b·r_m + c·L_t + ε`，取 **c** 为因子。
   `r_i` 用**全部可得**的月度收盘到收盘收益（2026-10-05 前误用组建日股票池筛选后的收益，覆盖 69% → 76%；方法文档 §二十三）

**性质**：c > 0 表示市场流动性恶化时该股跌得更多（流动性风险暴露高），
按 PS 原文应要求更高预期收益。
**来源**：[af] `factorcal.py: FactorLiquidityBeta`

### 28-32. ap_beta1~5 — Acharya-Pedersen (2005) 五个流动性 Beta

**构建**：先把 Amihud 非流动性折算成交易成本（AP 式 (12)）

```
c_i,t = min(AP_C1 + AP_C2 · ILLIQ_i,t · mv_ratio_t,  AP_C3)      # 0.25 / 0.30 / 60
```

`mv_ratio` = 市场总市值相对基期的比值（通胀调整，上限 30）。随后 36 月滚动：

| | 定义 | AP 理论预期 | 实测均值 |
|---|---|---|---|
| β1 | Cov(R_i, R_M) / Var(R_M − C_M) | ≈ 1 | **+0.84** ✅ |
| β2 | Cov(c_i, c_M) / Var(R_M − C_M) | > 0 | **+0.65** ✅ |
| β3 | Cov(R_i, c_M) / Var(R_M − C_M) | < 0 | **−0.07** ✅ |
| β4 | Cov(c_i, R_M) / Var(R_M − C_M) | < 0 | **−0.16** ✅ |
| β5 | β2 − β3 − β4 | > 0 | **+0.88** ✅ |

五个符号全部与 AP(2005) 的理论预期吻合，是这批实现最强的正确性证据。

> ⚠️ **量纲陷阱（必读）**：这里**不能**用全局 `ILLIQ_SCALE`(=1e5)。
> AP 的 c1/c2/c3 是一组**有量纲**的标定值，只在 ILLIQ 落在 O(0.01~1) 时有意义。
> 参照实现 `factorcal.py` 的 `amount` 单位是**千元**，而 Database 的
> `amt.csv` 单位是**元**，差 1000 倍。直接沿用 1e5 会让 ILLIQ 中位数只有
> 2.6e-5，于是 `c ≡ 0.25` 几乎完全是常数（实测截面标准差 0.002 vs 水平 0.25），
> β2~β4 全部退化成纯噪声（首次实现时 β2~β5 均值全是 0.000，即此故障）。
> 故 AP 内部单独用 `AP_ILLIQ_SCALE = ILLIQ_SCALE × 1000 = 1e8`。
>
> 不改全局 `ILLIQ_SCALE`：对 `amihud` 而言它只是单调缩放（不影响 IC/分组），
> 改了反而使既有缓存失效、与历史结果不可比。

**来源**：[af] `factorcal.py: FactorLiquidityBetaAP`

| ps_liq_beta | -0.0047 | -0.049 | -2.15% | -0.204 | 197 | ✗ 无预测力 |

（`ff3_betas` = β_mkt 口径未变，仍为 IC -0.0084 / ICIR -0.071）

### 结论：β 家族在 A 股整体无效，只有 AP 流动性 Beta 有信号

**1. 纯 β 载荷类全军覆没**（`capm_beta` / `beta_smb` / `beta_hml` / `ff3_betas`，
|IC| < 0.018、|ICIR| < 0.11）。这与文档中对 `ff3_betas` 的既有判断一致，
现在有了完整的四点证据：**A 股的截面收益不由因子载荷定价，而由特征定价**。
这本身是可写进论文的结论（Daniel-Titman 特征 vs 载荷之争在 A 股的证据）。

**2. PS 系列同样无效**（`ps_gamma` ICIR -0.087、`ps_liq_beta` -0.049），
尽管 γ 的符号分布完全正确（57% 为负）。说明「构建正确」与「有预测力」是两回事。

**3. 唯一亮点是 AP 的 β2 / β5**（ICIR 0.226 / 0.241，LS 夏普 0.97 / 1.01）。
两者高度相关（β5 = β2 − β3 − β4，而 β3/β4 量级远小于 β2），本质是同一个信号：
**流动性共动**——自身流动性与市场流动性同涨同跌的股票，要求更高回报。
强度上与 `overnight_ret`(ICIR 0.215) 相当，弱于合成池现有成员。

**是否入合成池：暂不**。理由：① 与既有 `amihud` 系列同属流动性大类，需先测相关性；
② 期数只有 198（36 月滚动窗口吃掉了 3 年），会缩短合成因子的可用区间。

**对 ML 的意义**：这 11 个因子虽然单因子弱，但**仍应作为特征进入 ML 面板**。
GBRT / RF 的价值恰在于捕捉弱信号间的非线性交互，线性 IC 低不等于无信息量。
GKX 原文中 `beta` 类变量的单变量预测力同样很弱，但在树模型里仍有贡献。

### 三个主要发现

**1. `amihud_vwap` 全面优于既有 `amihud`** ⭐⭐⭐

| | RankIC | ICIR | LS 夏普 |
|---|---|---|---|
| `amihud`（收盘价口径） | +0.0556 | 0.369 | 1.100 |
| **`amihud_vwap`（VWAP 口径）** | **+0.0795** | **0.515** | **1.324** |

用 VWAP 而非收盘价计算日收益，Amihud 的价格冲击度量更贴近**平均成交成本**，
不受尾盘操纵与收盘集合竞价干扰。ICIR 提升 40%。
**这是 Choice 数据相对 CRSP/JKP 的独有优势**——美国学术数据库不提供日内 VWAP，
故这类特征在英文文献里几乎见不到。建议后续考虑用它替换合成池中的 `amihud`
（需先做相关性与稳健性检验）。

**2. MAX effect 在 A 股很强，符合散户主导市场的预期**

`rmax1_21`（ICIR -0.575）与 `rmax5_21`（-0.532）都显著。彩票型偏好——
散户追逐近期有极端上涨的股票，推高价格，导致后续收益偏低。
配合 `skew_21`（-0.409）同向，三者共同刻画同一个行为金融现象。

**3. 动量在 A 股是系统性失效，不限于某个窗口**

新增的 6 个动量窗口（`ret_2_1` / `ret_3_1` / `ret_6_1` / `ret_9_1` /
`ret_12_7` / `ret_36_13`）**全部** |ICIR| < 0.23，且多数为负号（即弱反转）。
这把既有 `momentum_12_1`（ICIR -0.102）的单点结论强化成了**跨全部期限结构的
系统性证据**：A 股截面上不存在可用的价格延续效应，只有不同强度的反转。

> `prc_high_252`（52 周高点接近度）方向与 George-Hwang (2004) 的美股结论**相反**
> （我们 IC 为负 = 越接近高点后续收益越低），同属上述反转格局，
> 但强度弱（ICIR -0.150），暂不深究。
> 2026-10-05 核查构造：当前后复权收盘价 ÷ 过去 252 日最高收盘价，与 George-Hwang (2004) / JKP `prc_highprc_252d` 一致，
> **方向相反是 A 股实证结果而非构造错误**（与动量全期限失效一致）。

### ⚠️ `zero_trades_21` 分组回测不可用，但保留给 ML

> **已取代（历史记录）**：`zero_trades_21` 后改为 `zero_trades_252`（Liu 2006 标准化换手率调整零成交天数，`expansion.calc_zero_trades_252`），
> 已不在 `FACTOR_FLAGS` 与缓存中。下文保留作当时的诊断记录。

因子本身构建成功（非空 52%），但**五分组回测抛 `division by zero`**。
根因是数据的真实性质而非 bug：A 股绝大多数股票从不停牌，截面上

| 截面 | 众数占比 | 不同取值数 |
|---|---|---|
| 2012-12-31 | 96.1% | 5 |
| 2020-06-30 | 98.8% | 4 |
| 2026-07-31 | 99.5% | 3 |

`qcut` 分位边界重复 → 分组塌陷（与 §注2 的 `dividend_yield` 同类故障）。
`FACTOR_FLAGS` 已置 `False`，**但缓存仍会生成**。树模型对这种长尾二元特征
没有问题（直接按「是否停过牌」切一刀），**ML 阶段应重新纳入**。

> 实现注意：本因子必须在**套股票池掩码之前**计算。`build_investable_mask`
> 要求 `trade_status == 1`，先套掩码会把停牌日全抹成 NaN，于是 `is_zero`
> 恒为 0、截面标准差为 0、`preprocess` 标准化除零 → 整张表 NaN
> （首次实现即此故障，非空率 0%）。
